
* * * =========================== ESBMC 8.4.0 ============================ * * *

Main Usage:
  --input-file file.c ...               Source file names

Options:
  -? [ --help ]                         Show help
  --function name                       Set main function name
  --class cname                         Set the class/namespace name where the 
                                        function is inside
  --claim nr                            Only check specific claims
  --instruction nr                      Limit the number of instructions 
                                        executed during symbolic execution
  --git-hash                            Show ESBMC version with git hash and 
                                        exit
  --version                             Show current ESBMC version and exit
  --verbosity arg                       Verbosity of log output, can be given 
                                        multiple times. Parameter is either a 
                                        decimal N or 'module:N' to set the 
                                        log-level of debug messages of the 
                                        module to N; without module, it sets 
                                        the global log-level

Printing options:
  --symbol-table-only                   Only show symbol table
  --symbol-table-too                    Show symbol table and verify
  --parse-tree-only                     Only show parse tree
  --parse-tree-too                      Show parse tree and verify
  --goto-functions-only                 Only show goto program
  --goto-functions-too                  Show goto program and verify
  --dump-goto-cfg                       Create a file for each function with 
                                        the associated CFG in DOT format
  --show-call-sites                     Show each function call site with its 
                                        arguments
  --program-only                        Only show program expression
  --program-too                         Show program expression and verify
  --ssa-symbol-table                    Show symbol table along with SSA
  --ssa-guards                          Print guard expressions in SSA output
  --ssa-sliced                          Print the sliced SSAs
  --ssa-no-location                     Omit location info from SSA output
  --smt-formula-only                    Only show SMT formula (not supported by
                                        all solvers)
  --smt-formula-too                     Show SMT formula (not supported by all 
                                        solvers), and verify
  --smt-model                           Show SMT model (not supported by all 
                                        solvers), if the formula is SAT
  --color auto|always|never (=auto)     Show colored output
  --log-message                         Print LOG message including file, line,
                                        and timestamp
  --keep-alive-interval interval        Set interval (in seconds) for keep 
                                        alive messages (default: 60)
  --enable-keep-alive                   Enable keep alive messages during long 
                                        solving processes

Trace:
  --quiet                               Do not print unwinding information 
                                        during symbolic execution
  --compact-trace                       Enable --no-slice and hide internal 
                                        symbols from the trace
  --symex-trace                         Print instructions during symbolic 
                                        execution
  --ssa-trace                           Print SSA during SMT encoding
  --ssa-smt-trace                       Print generated SMT during SMT encoding
  --ssa-features-dump                   Print features in the SSA (just before 
                                        conversion)
  --symex-ssa-trace                     Print generated SSA during symbolic 
                                        execution
  --show-goto-value-sets                Show value-set analysis for the goto 
                                        functions
  --show-symex-value-sets               Show value-set analysis during symbolic
                                        execution
  --show-stacktrace                     Show the stack trace of function call 
                                        in the counterexample
  --simplify-trace                      Simplify the trace and exclude the 
                                        assignments whose variables are not 
                                        from user-input files

Python frontend:
  --python path                         Python interpreter binary to use 
                                        (searched in $PATH; default: python)
  --override-return-annotation          Override return annotation with 
                                        inferred type
  --strict-types                        Enforce strict type checking for 
                                        function arguments during verification
  --python-no-fold                      Disable NumPy constant folding in the 
                                        Python frontend
  --nondet-str-length nr (=16)          Set maximum length for 
                                        non-deterministic strings (default is 
                                        16)
  --python-list-compare-depth nr (=4)   Set maximum nesting depth for Python 
                                        list comparison (default is 4)
  --python-irep2-adjust                 Run the IREP2-native Python adjuster 
                                        alongside the legacy adjust pass (V.4 
                                        migration; experimental, default off)

Solidity frontend:
  --sol path                            Solidity source file (.sol) — also 
                                        accepted as a positional argument
  --solc-bin path                       path to solc binary (default: $SOLC or 
                                        solc in $PATH)
  --contract cname                      Set contract name
  --focus-function name                 Restrict the contract harness to verify
                                        only the named public/external 
                                        function. The constructor and state 
                                        initialization still run (unlike 
                                        --function), but the nondet dispatch 
                                        loop calls only this function. Requires
                                        --contract when the source declares 
                                        more than one contract.
  --no-visibility                       Force to verify every function, even if
                                        it's an unreachable internal/private 
                                        function
  --unbound                             Model external function calls as 
                                        arbitrary behavior
  --bound                               Model inter-contract function calls 
                                        within a bounded system (default)
  --reentry-check                       Detect reentrancy behavior during 
                                        contract execution
  --negating-property fname             Convert the assert(cond) to 
                                        assert(!cond)

Frontend:

  --include-file file                   Include files via frontend's -include 
                                        option before anything else
  --nostdinc                            Do not include from standard system 
                                        paths
  --idirafter path                      Append system include path to search 
                                        after system headers
  -D [ --define ] macro                 Define preprocessor macro
  -W [ --warning ] arg                  Enable specific frontend warnings, 
                                        disable with "no-" prefix, or pass 
                                        options directly to the C/C++ frontends
                                        with the form -Wc,OPT1,OPT2,...
  --std version                         Set C/C++ standard version
  --sysroot <path>                      Set the sysroot for the frontend
  --no-abstracted-cpp-includes          Do not include abstract C++ operational
                                        models
  -f [ --force ] arg                    Pass -f flags to the C/C++ frontend
  --preprocess                          Stop after preprocessing
  --no-inlining                         Disable inlining function calls
  --full-inlining                       Perform full inlining of function calls
  --all-claims                          Keep all claims
  --keep-verified-claims                Do not skip verified claims in 
                                        multi-property verification
  --show-loops                          Show the loops in the program
  --show-claims                         Only show claims
  --show-vcc                            Show the verification conditions
  --no-library                          Disable built-in abstract C library
  --no-string-literal                   Ignore string literals (replace with 
                                        NULL)
  --binary                              Read goto program instead of source 
                                        code
  --cprover                             Deprecated no-op (kept for backward 
                                        compatibility)
  --no-cprover-additions                Do not auto-link ESBMC additions when 
                                        reading a CBMC goto-binary
  --dont-care-about-missing-extensions  Don't crash on unsupported extensions
  --old-frontend                        Parse source files using the old 
                                        frontend (deprecated)
  --funsigned-char                      Make "char" unsigned by default
  --fms-extensions                      Enable microsoft C extensions
  --argv-max-args nr (=2)               Maximum number of argv entries backed 
                                        with nondet strings (default 2). Higher
                                        values widen coverage at the cost of a 
                                        larger SMT formula.
  --argv-max-strlen nr (=256)           Maximum length (in bytes, including the
                                        null terminator) of each backed argv 
                                        string (default 256).
  --gcc-nested-functions                Enable GCC nested functions extension 
                                        (source-level lambda lifting)
  --sv-comp                             Enable SV-COMP mode: suppress 
                                        GCC-acceptable frontend diagnostics 
                                        (int/pointer conversions), treat 
                                        __builtin_unreachable as a no-op, emit 
                                        physical line numbers for witnesses, 
                                        and avoid malloc/free in the 
                                        fopen/fclose models. Set automatically 
                                        by the SV-COMP wrapper.

  --big-endian                          Allow big-endian word-byte conversions
  --16                                  Set width of machine word (default is

Witness:
  --witness-output path                 Generate the verification result 
                                        witness in both Yaml and GraphML format
  --sarif-output { path | - }           Generate a SARIF 2.1.0 report of the 
                                        violation; use '-' for stdout. Each 
                                        result is annotated with the matching 
                                        CWE ids (CWE 4.20).
  --witness-output-graphml { path | - } Generate the verification result 
                                        witness in GraphML format; use '-' for 
                                        output to stdout
  --witness-output-yaml { path | - }    Generate the verification result 
                                        witness in Yaml format; use '-' for 
                                        output to stdout
  --witness-producer arg                Override the producer name in witness 
                                        files
  --witness-programfile arg             Override the program file name in 
                                        witness files
  --validate-correctness-witness        Validate the YAML correctness witness 
                                        (2.0)
  --validate-violation-witness          Validate the YAML violation witness 
                                        (2.0)
  --witness <path>                      Set the witness path
  --all-witnesses                       After a property fails, enumerate 
                                        further input vectors that also violate
                                        it (until UNSAT or --max-witnesses is 
                                        reached). Implies --multi-property.
  --max-witnesses n (=16)               Cap the number of witnesses reported 
                                        per property (default: 16; 0 = 
                                        unlimited). Only meaningful with 
                                        --all-witnesses.

Output:
  --output-goto arg                     Export generated goto program
  --cex-output arg                      Save the counterexample into a file or,
                                        in multi-property mode, multiple files 
                                        with name prefix 'N-' where 'N' is a 
                                        decimal increasing from zero
  --file-output arg                     Redirect all output to a file (no 
                                        stdout/stderr)
  --goto2c                              Translate the GOTO program to C
  --generate-testcase                   If a solution is found, generates a 
                                        testcase in XML
  --generate-pytest-testcase            If a solution is found, generates a 
                                        pytest testcase for Python programs
  --generate-ctest-testcase             If a solution is found, generates CTest
                                        testcases for C programs
  --generate-html-report                If a violation is found, generates a 
                                        HTML report
  --generate-json-report                If a violation is found, generates a 
                                        JSON report
  --result-only                         Do not print the counter-example

                                        name with nr times.
                                        Syntax: func, N@ns@func, 
                                        S@Class@method, file.c@func,
                                                N@ns@S@Class@method, 
                                        file.c@N@ns@S@Class@method
                                        Also accepts Clang USR format (e.g., 
                                        c:@F@func# or c:file.c@F@func#)
                                        Example: --unwindsetname 
                                        compute:0:10,N@math@sum:1:5
                                        Use --show-loops to see available 
                                        functions and loop indices
  --no-unwinding-assertions             Do not generate unwinding assertions
  --no-remove-unreachable               Disable the removal of unreachable code
                                        in GOTO programs
  --no-remove-no-op                     Disable the removal of NO-OP 
                                        instructions in GOTO programs
  --partial-loops                       Permit paths with partial loops
  --no-slice                            Do not remove unused equations
  --multi-fail-fast n                   Stop after first n VCC violations in 
                                        multi-property mode
  --no-slice-name name                  Disable slicing for all symbols 
                                        generated with the given name
  --no-slice-id id                      Disable slicing for the symbol with the
                                        given id
  --goto-unwind                         Unroll bounded loops at goto level
  --unlimited-goto-unwind               Do not unroll bounded loops at goto 
                                        level (need to enable --goto-unwind)
  --slice-assumes                       Remove unused assume statements
  --skip-bmc                            Do not perform bounded model checking
  --no-cache-asserts                    Do not cache asserts that were already 
                                        proven correct

IREP2 migration (esbmc/esbmc#4715):
  --irep2-bodies                        Deprecated no-op (accepted for backward
                                        compatibility). goto_convert always 
                                        lowers function bodies through the 
                                        IREP2 round-trip (migrate legacy codet 
                                        → code_*2t → codet) since V.4.4; 
                                        the legacy bypass and the 
                                        --no-irep2-bodies escape hatch have 
                                        been removed.
