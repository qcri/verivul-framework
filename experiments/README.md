# Experiments

Code and reported results for the evaluation of the dataset. The framework does not import anything from here. Inputs and outputs are listed in [../docs/experiments.md](../docs/experiments.md).

| Folder | Experiment |
|---|---|
| `benchmark/` | zero-shot LLM evaluation |
| `realism/` | distance of VeriVul to real-world corpora |
| `contamination/` | prefix-completion memorisation probe |

```bash
pip install -r experiments/requirements.txt
```
